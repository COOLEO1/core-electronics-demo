# Core Electronics — website concept

A responsive static storefront concept by **Golden-Rhys Company**, prepared for presentation to Core Electronics Malawi.

## Render deployment
Create a **Static Site** in Render and connect this repository:
- **Repository:** `COOLEO1/core-electronics-demo`
- **Branch:** `main`
- **Build command:** leave blank
- **Publish directory:** `.`

Then deploy.

## Included experience
- Responsive desktop and mobile layout
- Product category tiles and catalogue cards
- Live product search and category filtering
- Product enquiry message preparation and copy interaction
- General enquiry form that prepares a message for the visitor
- Mobile navigation

## Important before a real launch
This is a demonstration concept, not the official Core Electronics website. Product names, descriptions, product imagery and catalogue entries are illustrative placeholders. Confirm the actual product range, specifications, prices, stock, official business contacts, address and social links with Core Electronics before publication.

The enquiry form currently prepares a message for the visitor to copy; it does not submit to a business inbox or WhatsApp account. Connect it to a verified destination only after the business confirms its preferred contact channel.

Images are loaded from Unsplash and fonts from Google Fonts, so those assets require an internet connection.
